CHEETAH LUDO: WINDOWS 10 / WINDOWS 11
=====================================

METHOD A - PLAY NOW WITH JAVA 17+ INSTALLED
1. Extract this ZIP file fully (do not run it from inside the ZIP).
2. Open CheetahLudoEclipse folder in File Explorer.
3. Double-click RUN_ON_WINDOWS.bat
4. The program checks Java/resources, then opens a separate Swing game window.

METHOD B - RUN/EDIT IN ECLIPSE IDE
1. Install JDK 17+ and Eclipse IDE for Java Developers.
2. File > Import > General > Existing Projects into Workspace.
3. Select the CheetahLudoEclipse folder (containing .project).
4. Open src/com/cheetahludo/Main.java > Run As > Java Application.
   Or right-click CheetahLudo-Game.launch and run it.
   NOTE: CheetahLudo-Check.launch ONLY prints diagnostics; it does not show a game.

METHOD C - PACKAGE THE GAME AS A WINDOWS EXE (NO JAVA NEEDED BY PLAYERS)
1. On Windows, install a full JDK 17+ (JDK 21 recommended).
2. Double-click BUILD_WINDOWS_APP.bat.
3. Find release/CheetahLudo/CheetahLudo.exe.
4. Distribute the ENTIRE release/CheetahLudo folder. The Java runtime is included.
   BUILD_WINDOWS_APP.bat must run ON Windows, not on macOS.

HELP
- If Java is not on PATH, set JAVA_HOME to the installed JDK folder.
- Install Java: https://adoptium.net/
- If there is no GUI but the Console says CHECK PASSED, you ran the
  CheetahLudo-Check launcher, NOT CheetahLudo-Game.
- See README.md and docs/TROUBLESHOOTING.md for more information.
